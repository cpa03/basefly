## 4. Critical Environment/CI Finding — Node version mismatch

**Finding:** `next build` fails on Node 20 with:

```
unhandledRejection TypeError: webidl.util.markAsUncloneable is not a function
```

**Root cause:** `undici@8.10.0` (`lib/web/webidl/index.js`) requires `markAsUncloneable` from `node:worker_threads`, added in Node 22. Verified: present in 22.14.0/22.22.0/24.19.0, **absent in 20.20.2**.

**Impact:** Both CI workflows pin `node-version: 20` (on-pull.yml line 55; iterate.yml lines 70/266/340/395). Any build verification inside CI fails. `.github/scripts/security-audit.yml` already correctly uses 22.

**Fix prepared (see §6)** — blocked from push by missing `workflows` permission.
