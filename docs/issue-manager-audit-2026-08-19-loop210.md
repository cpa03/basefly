## 5. NEW: Security Audit Investigation (`@opentelemetry/core` moderate)

**Finding (fresh this loop):** `pnpm security:audit` (`pnpm audit --audit-level=moderate`) **fails**:

```
moderate | OpenTelemetry Core: Unbounded memory allocation in W3C Baggage propagation
Package: @opentelemetry/core | Vulnerable: <2.8.0 | Patched: >=2.8.0
Paths: apps__nextjs>contentlayer2>@contentlayer2/utils>@opentelemetry/core
```

**Root cause analysis:**

- Root `package.json` overrides: global `"@opentelemetry/core": ">=2.8.0"` (line 127) + **scoped `1.30.1` pins** for the contentlayer2/@effect-ts subtree (lines 129–134).
- The scoped pins exist because the legacy OTel 1.x SDK chain (`@effect-ts/otel@0.15.1`, `sdk-trace-base@1.30.1`, `sdk-trace-node@1.30.1`, `exporter-trace-otlp-grpc@0.51.1`) **requires core 1.x**.
- `contentlayer2@0.5.8` (latest) still depends on `@opentelemetry/core ^1.30.1` — **no upstream fix exists**; upgrading contentlayer2 does not resolve it.
- **No patched 1.x release exists** (advisory patches only `>=2.8.0`).

**Why this is a documented accepted risk (do NOT change):**

- Commit `9c16f6a` (2026-08-02, "fix(deps): scope OpenTelemetry core override to fix build break") documents that the global `>=2.8.0` override (added in #1049) **broke the build on main and every PR** with `TypeError: Cannot read properties of undefined (reading 'AlwaysOn')` at `@opentelemetry/sdk-trace-base@1.30.1 .../config.js`. The scoped pins are the deliberate, verified fix.
- The vulnerable instance is reachable **only** through contentlayer2 — a **build-time** MDX tool whose tracing is **opt-in and not enabled** (`apps/nextjs/contentlayer.config.ts` contains no tracing config) and which never parses untrusted HTTP headers (the W3C Baggage DoS vector). Runtime paths (Sentry/PostHog) resolve `@opentelemetry/core@2.10.0` — patched.
- The maintainer explicitly accepted this residual: _"audit: runtime paths clean; 1 moderate remains only in contentlayer2 (build-time tool, no runtime HTTP exposure)."_

**Action:** no override change made (would reintroduce the verified build break). Documented for maintainer awareness; the `security:audit` gate stays red by design until contentlayer2 upstream moves off core 1.x.
